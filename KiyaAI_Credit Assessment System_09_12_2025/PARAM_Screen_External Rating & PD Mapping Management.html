About External Rating Mappings
  • Purpose: This master table maps external credit ratings from recognized agencies to internal ORR grades (1-8).
  • Investment Grade: Grades 1-4 represent Investment Grade ratings with lower credit risk.
  • Below Investment Grade: Grades 5-8 represent speculative or high-risk ratings.
  • Access Control: Only users with "Rating Administrator" role can modify these mappings.
  • System Impact: Changes affect all credit assessments system-wide. Ensure accuracy before saving.

About PD (Probability of Default) Mapping
  • Purpose: Define the Probability of Default (PD) percentage for each internal grade (1-8).
  • Usage: PD values are used for unrated loan calculations, risk-weighted assets (RWA), and capital adequacy.
  • Averaging Rules: Unrated loans use grade-averaged PD values as per policy guidelines.
  • Calibration: PD values must be reviewed annually and aligned with S&P default rate statistics.
  • Impact: Changes affect all PD-based calculations across the system.
