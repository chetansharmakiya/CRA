Parameter Management

Credit Assessment - Parameter Configuration

Configure all parameter types: Financial Ratios, Qualitative Factors, Mandatory Adjustments, and Discretionary Overrides. All changes auto-deploy to database and API.

How This System Works

  • Add Parameter: When you add a parameter, the system automatically creates a database column, generates API endpoints, and adds an input field to the credit assessment stepper.
  • Financial Parameters: Define formulas and scoring ranges. Backend calculation engine applies these during assessment.
  • Qualitative Parameters: Define dropdown/radio options with scores. User selections are stored and scored.
  • Mandatory Adjustments: System-enforced score penalties/bonuses based on data quality, audit reports, etc.
  • Discretionary Overrides: Allow senior officers to manually adjust final ratings with justification.

Mandatory Adjustments

Mandatory Adjustments: System-enforced score modifications based on:
  • Age of financial information (older data = penalty)
  • Audit report qualifications (qualified reports = penalty)
  • Account conduct issues (defaults, delays = penalty)
  • Data quality and completeness
These adjustments are automatically applied and cannot be bypassed.

Discretionary Overrides

Discretionary Overrides: Allow senior credit officers to manually adjust final rating grades:
  • Upgrade or downgrade rating by specified notches (e.g., BBB+ to A-)
  • Requires justification and approval workflow
  • Based on qualitative judgment, forward-looking view, or exceptional circumstances
  • Fully auditable with timestamp and officer ID
